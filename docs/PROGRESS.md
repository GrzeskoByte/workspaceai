# WorkspaceAI — implementation progress

Source of truth: [DESIGN.md](DESIGN.md) (exported from the Claude Docs design document) and the
design canvas copied into [`design/`](../design) (`App.dc.html` is the interactive prototype).

## Architecture as built

| Piece | Where | Notes |
|---|---|---|
| Shared model + logic | `packages/shared` | Types, opencode.json builders, schedule parser (chrono-node + repeats), BPMN lint rules, fuzzy search |
| Supervisor | `packages/supervisor` | Node HTTP+SSE on 127.0.0.1 with a per-launch token. Owns workspaces, starts one `opencode serve` per workspace (XDG-isolated, random password), keychain, policy, audit |
| Memory MCP | `packages/memory-mcp` | stdio MCP server per workspace: `memory.search`, `memory.read`, `memory.write` |
| Orchestrator | `packages/orchestrator` | bpmn-engine runner called by the supervisor, not a separate process. State is saved when a step reports it |
| UI | `apps/ui` | React + Vite; Claude Warm Editorial tokens, opencode theme alternate. `npm run dev` serves it at 127.0.0.1:5173 |
| Desktop shell | `apps/desktop` | Tauri 2 shell under `apps/desktop/src-tauri`; starts the supervisor and loads the built UI. `scripts/dev.mjs` runs supervisor + Vite for development |

## opencode v2 facts (verified against opencode 2.2.1)

See [opencode-v2-notes.md](opencode-v2-notes.md). The design doc names v1 routes (`/session`, `/event`, `/global/health`);
the installed v2 server serves them under `/api/*`, and WorkspaceAI follows the installed version.
